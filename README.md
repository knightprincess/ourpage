# Our Check-in 💌

Un espacio privado para mantenernos conectadas a pesar de la distancia y las 11 horas de diferencia horaria. 

## ¿Qué es este proyecto?
Es una aplicación web diseñada para que mi pareja y yo podamos hacer un "check-in" diario. Como nuestros horarios (Argentina - Rusia) no siempre coinciden para hablar en tiempo real, este espacio nos permite dejarnos respuestas intencionales, notas y pequeños detalles que nos hicieron acordar a la otra durante el día.

## Tecnologías
Construido con HTML, CSS y Vanilla JavaScript.
